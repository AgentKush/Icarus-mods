Author: AgentKush

Compatible with Icarus: All Weeks

Mod Type: EXMOD

## Description:
Adds 11 legendary weapons to the Workshop: the 9 the Bio Lab sells (Frontier Revolver, Kinetic
Rifle, Tactical Bow, Mining Armature, Biotech Maul, Heavy Flamethrower, Anti-materiel Rifle,
Javelin Launcher, Timber Extraction Unit) plus Frostbreaker and the Slugger, which the game
defines but never hands out.


Ver 2.1
The Slugger works. The game has its icon, gun, back tank, firing logic and slime projectile but
never added the item row that ties them together, so the Workshop showed "ICON MISSING". The mod
adds that row from the game's own Slugger parts. It fires slime globs (250 damage) and runs on
water from a 30 L tank that takes water the way the Fire Extinguisher does; you can't drink from
it. Each shot uses 1 L (30 shots a tank): the game sets no cost, so that is this mod's choice.
It can't be upgraded at the Bio Lab, which has no upgrade page for it.
Weapon names updated to the game's current ones: Biotech Maul (Ape Club), Frostbreaker (Ice
Mammoth Sledgehammer), Timber Extraction Unit (Sandwyrm Chainsaw), Slugger (Slug Launcher).

Ver 2.0.1
New icon and banner, drawn from the mod's live data. No gameplay change.

Ver 2.0
Fixed Flamethrower case mismatch (FlameThrower -> Flamethrower), added Sandwyrm Chainsaw.
