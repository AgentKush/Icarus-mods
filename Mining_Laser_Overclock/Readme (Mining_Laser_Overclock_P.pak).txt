Mining_Laser_Overclock
----------------------------------------------------------------------
Mod Version: 1.0.2
Author: AgentKush
Compatible with Icarus: All Weeks
Mod Type: EXMODZ (PAK / blueprint)

## Description:
The first-ever mining-laser blueprint mod. The mining laser runs 300 seconds before overheating (was 5s) and cools in 1s (was 5s) - sustained, uninterrupted deep mining. Byte-patches SecondsToReachMaxHeat and SecondsToCooldown in BP_Actionable_MiningLaser.

Ver 1.0.2
Rebuilt BP_Actionable_MiningLaser from the 19 November 2026 game files with the same two
changes: 300 seconds before overheating (was 5) and a 1 second cooldown (was 5). The old copy
dated from June 2026, and the game has since added 4 fields to the laser's shot
data (BallisticData, 32 fields, now 36), so the old blueprint no longer matched it when the
laser fires.

Ver 1.0.1
New icon and banner, drawn from the mod's live data. No gameplay change.

Ver 1.0
Initial release.

## Installation:
  1. Install JimK72's Icarus Mod Manager
  2. Import Mining_Laser_Overclock.EXMODZ
  3. Rebuild the merged mod and restart Icarus
