## Overview

Icarus has weapons, tools and gear in its files that players can never get: their models, icons and logic ship with the game, but no recipe, shop or reward hands them out, and most are missing the item row that turns them into a usable item. Agent's Hidden Things adds those missing rows and puts every item that works into one Workshop tab, **Agent's Hidden Things**.

- **Direct (17 items):** gear the game made for the Workshop is bought and replicated like any Workshop item, at the game's own prices where the game set one.
- **Kit (40 items):** everything else comes as a kit, like Agents Individual Item Kits. Buy it in the Workshop, take it down with you and use it to get the item. The Workshop shows no stats for a kit, so each kit's description says what its item does. Each kit costs what Item Kits charges for the item's closest released twin.

Every value comes from the game's own data. Where the game never set one, the item copies its closest released twin, and the notes below say so.

## Borrowed art and known limits

The game never finished these items, so some reuse art from released items or behave in unexpected ways.

- **MX-7 Rotary Grenade Launcher:** uses the Slugger's icon, gun body and firing sound, and its spinning drum may not show. It loads one grenade at a time and can't be upgraded at the Bio Lab.
- **Tri-Barrel Launcher:** borrows the Single Barrel Launcher's icon. Its name and description come from the game's own text file.
- **CHAC Assault Rifle and CHAC Submachine Gun:** Workshop copies of the craftable Assault Rifle and Submachine Gun, with the same look and firing stats.
- **Thornet Pistol:** looks and fires like the Semi-Automatic Pistol and borrows its icon.
- **Vineshade Bow:** the Wood Bow's model, sound and power with twice the durability; it borrows the Wood Bow's icon.
- **Thornet Trophy:** uses the Scorpion tail trophy's model and icon.
- **Thornet Backpack:** looks like the Explorer Backpack and adds no inventory slots. The game's placeholder text promised a wingsuit, which doesn't exist.
- **EMP Grenade:** borrows the Impact Grenade's look.
- **Marrowraith Trap:** the game built it as a copy of the Bramble Bush. It deals no hit damage, gives anything that walks into it the Spiked Brambles debuff (players included), and its blades don't spin.
- **Felixus Gauntlets:** punch with the bare-fist animations.
- **Felixus Module:** only works in grassland biomes (on Prometheus: the Grassy Plains, Sylvan Range and Wildwoods).
- **Heavy Woolly Mammoth Saddle:** a mammoth can wear it only after learning the new Foundational creature talent (after Big Rig). The deployable platforms its text describes are untested.
- **Marrowraith Spear:** 4,000 durability, so it wears out fast.
- **Marrowraith Spine, Thornet Wing and Thornet Stinger:** collectibles. No recipe in the game uses them.

## Changes to the game's own rows

Besides the new item rows, the mod fixes the unreleased rows these items use. No released item uses any of the rows below.

- Replaces "[DNT]" placeholder names with real ones: Marrowraith Module, Marrowraith Armor Attachment, Thornet Backpack, Thornet Throwing Module, Thornet Venom Attachment and Felixus Module.
- Adds the missing icons and descriptions of the Thornet Pistol, Thornet Trophy, Vineshade Bow, Felixus Gauntlets, Heavy Woolly Mammoth Saddle and EMP Grenade.
- **Tri-Barrel Launcher:** adds its name row, and lets a Repair Bench repair it.
- **Thornet Pistol:** gets the fire rate and reload time of the pistol it copies, which the game left out.
- **Marrowraith Bolt:** fires from the crossbow like other bolts. The game's row kept the arrow's spawn point.
- **Building Upgrade Tool:** right-click now swaps the piece. The game's row put the swap on left-click, which does nothing.
- **DNA Augmentation Serum:** raises physical resistance, as its description says. The game's row lowered it.
- **Camo and Synthetic Backpacks:** repair with Cured Leather. The game's rows asked for a whole Fabricator or Manufacturer.
- **Felixus Gauntlets:** show the Felixus fur arms and drop as the Felixus pack, instead of the carbon-fibre placeholders.
- **Heavy Woolly Mammoth Saddle:** adds the mammoth talent Foundational, whose text the game still has, and seats the rider like the standard mammoth saddle.
- **Thornet Venom Attachment:** shows the Thornet icon instead of the Scorpion's.
- **Forced Evolution Virus:** adds the "Animal Testing" accolade the virus asks for when you use it on a mount.

## Left out

- **Vineshade Module:** its stats only work in Jungle biomes, and no map has one.
- **Tame Capture Device:** unfinished; a tame stored in it can be lost.
- **Norex Radio:** it looks for a contract station that nothing in the game spawns, so it never connects.
- **Night Vision, the Slugger and the dev tools:** in Night Vision Goggles, Agent's BioLab and Dev Tools Kit.
- **Names only:** the energy rifles, a sniper rifle and a scoped hunting rifle exist only as names in the files.

## Installation

1. Download the `.EXMODZ` file from this repository
2. Open JimK72's Icarus Mod Manager
3. Import the mod file
4. Enable and launch Icarus
5. Find the items in the Workshop under Agent's Hidden Things
