Easier_Corpse_Runs
----------------------------------------------------------------------
Mod Version: 1.0
Author: AgentKush
Compatible with Icarus: All Weeks
Mod Type: EXMOD (data)

## Description:
Makes the run back to your body after a death quicker and safer. When you respawn while you're the only player in the game, the game gives you a short "Death Run" boost. This mod makes it much stronger: +30% movement speed (was +10%), sprinting costs 50% less stamina (was 20% less) and -50% perceived threat while sneaking (was -15%). Other actions keep the normal 20% stamina cut. It lasts as long as the normal boost: up to 5 minutes, ending when you open the bag your items were left in. The game only gives this boost while you are the only player in the game (also when you're alone on a hosted or dedicated server) and takes it away if another player joins, so the mod does nothing while you play with others. On a dedicated server, install the mod on the server too. Edits the DeathRun row in Modifiers-D_ModifierStates.json.

Ver 1.0
Initial release. Stronger Death Run respawn boost: +30% movement speed, sprinting costs 50% less stamina, -50% perceived threat while sneaking.

## Installation:
  1. Install JimK72's Icarus Mod Manager
  2. Download Easier_Corpse_Runs.EXMODZ
  3. Import via Mod Manager
