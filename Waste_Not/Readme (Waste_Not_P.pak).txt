Mod Version: 2.3

Author: CritFail (Updated by AgentKush)

Compatible with Icarus: All Weeks

Mod Type: EXMOD

## Description:
Mining yields useful secondary resources instead of Stone. Normal ores give bonus of the same type, dense metal ores drop Exotics. Coal gives Charcoal, Ice gives Oxite. Covers 26 of the game's 33 mineable deposit types - Limestone, Salt, Exotic, Frozen Ore and Research deposits are left at their vanilla values.

Ver 2.3
Fixed Dense Stone: it set the primary yield to Silica instead of the secondary, so the
game's main stone deposit stopped giving stone. It now gives Stone with Silica as the
bonus, like Normal Stone. Removed an unlisted change that made random-resource deposits
give Stone; that deposit is back to vanilla.

Ver 2.2
Current release. 33 deposit types covered. Originally by CritFail, updated by AgentKush
for the current game build. Earlier version history was not recorded.
